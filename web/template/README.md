# DOGWU Dating UI Replica

Responsive HTML/CSS/JavaScript recreation of the supplied DOGWU Dating screen.

## Mobile
The original mobile-style layout is preserved with bottom navigation.

## Desktop
At 900px and above, the UI becomes a desktop dashboard with:
- fixed left sidebar navigation
- wide premium banner
- horizontal story cards
- 4-column Recently Active grid
- desktop spacing and card sizing
- no mobile bottom navigation

Open `index.html` in a browser and resize the window to see both versions.
