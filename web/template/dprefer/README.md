# Dogwu Dating — Discover Preferences

A responsive HTML/CSS/JavaScript recreation of the supplied mobile design.

## Files
- index.html — page structure
- style.css — responsive styling
- script.js — buttons, switches, reset/apply interactions

## Run
Open `index.html` in any modern browser.

The layout is responsive from small phones through desktop screens. On larger screens it keeps the mobile-app visual proportions inside a centered app shell.
