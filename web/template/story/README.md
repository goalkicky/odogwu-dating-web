# Amaka Story — Responsive HTML/CSS/JavaScript Replica

## Files
- `index.html` — page structure
- `styles.css` — responsive sizing and layout
- `script.js` — interactive hit areas, share, toast and More menu
- `reference.jpg` — supplied 710 × 1536 reference image

## Run
Open `index.html` in a browser.

The story frame preserves the original 710:1536 aspect ratio, so the supplied design is not stretched. On desktop it stays centered like a vertical social-story screen; on phones it fills the available viewport while preserving the exact proportions.

The visible artwork is the supplied reference image itself. Transparent interaction zones are layered over the visible controls so the replica remains visually exact while still having working JavaScript interactions.
