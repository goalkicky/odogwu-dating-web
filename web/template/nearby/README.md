# Odogwu Dating — Responsive Replica

This project recreates the supplied 711 × 1536 design as a responsive HTML/CSS/JavaScript page.

### Files
- index.html
- styles.css
- script.js
- logo.png
- map.png
- adanna.jpg
- chinedu.jpg
- ifeoma.jpg
- zainab.jpg
- tobi.jpg
- amaka.jpg

The six profile-card image assets are cropped from the supplied reference so the people, photographs, badges, labels, distances and card visuals match the reference closely. The surrounding UI (header, nearby section, location button, premium banner, navigation and interactions) is built in HTML/CSS/SVG.

Open `index.html` in a browser. No build step is required.
